## المرحلة 2: التكامل مع قاعدة البيانات 🔄

### الأهداف:
- دمج Supabase كقاعدة بيانات
- حفظ البيانات بشكل دائم
- مزامنة فورية عبر المستخدمين

### المهام التقنية:
1. **إعداد Supabase Project**
   - إنشاء مشروع جديد
   - تصميم قاعدة البيانات (Tables)
   - إعداد Row Level Security (RLS)

2. **الجداول المطلوبة:**
   ```sql
   - users (المستخدمين)
   - employees (الموظفين)
   - visits (الزيارات)
   - infection_control (تقييمات مكافحة العدوى)
   - audit_logs (سجل التعديلات)
   ```

3. **API Integration**
   - استبدال mockData بـ Supabase queries
   - إضافة Real-time subscriptions
   - معالجة الأخطاء وحالات التحميل

4. **المدة المتوقعة:** 2-3 أسابيع
