# نظام إدارة الزيارات الميدانية ومكافحة العدوى | Field Visits Management and Infection Control System

## 🌐 Multi-Language Support | دعم اللغتين
النظام يدعم اللغتين العربية والإنجليزية بالكامل!
The system fully supports both Arabic and English languages!

### تبديل اللغة | Language Toggle
- اضغط على زر 🌐 في الـHeader للتبديل بين اللغتين
- Click the 🌐 button in the Header to toggle between languages
- يتم حفظ اللغة المختارة تلقائياً
- Your language preference is saved automatically
